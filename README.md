# Student Management System

A simple and attractive **Student Management System** built using **Python Flask**.

## 🚀 Features

* 👨‍🎓 Add new students
* 📋 View all student records
* 🔎 Search by Student ID, name, or course
* ✏️ Edit student details
* 🗑️ Delete student records
* 🔢 Automatic Student IDs starting from **101**
* 💾 SQLite database
* 📱 User-friendly web interface

## 🛠️ Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS
* Jinja2

## 🔎 Search

Students can be searched using:

* Student ID — `101`, `102`, `103`
* Student name — `Ajay`
* Course — `CSE`, `ECE`, etc.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Rebel12ajay/Student_manmagement_system.git
```

### 2. Open the project

```bash
cd Student_manmagement_system
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in your browser

```text
http://127.0.0.1:5000
```
